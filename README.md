# Map products of forest disturbance drivers in Southeast Asia

Reference: Chen, S., Woodcock, C. E., Gu, H., Dong, L., Tang, X., & Olofsson, P. (2026). Drivers of forest disturbance in Southeast Asia. International Journal of Applied Earth Observation and Geoinformation, 148, 105220. https://doi.org/10.1016/j.jag.2026.105220 

Zenodo link: https://zenodo.org/records/18841734 

Google Earth Engine link: https://ee-shijuan.projects.earthengine.app/view/forestdisdriver

Google Earth Engine asset name for the map: projects/ee-shijuan/assets/CMS_publish/Forest_Dis_Drivers_SEA 
Map values and classes:
1: Stable forest
2: Plantation
3: Non-forest
4: New Plantation
5: Deforestation
6: Shifting cultivation
